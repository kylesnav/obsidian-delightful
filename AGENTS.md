# obsidian-delightful

Obsidian community theme with modular CSS source files and generated `theme.css`.

## Source of Truth

Edit `src/` files. `theme.css` is generated by `build.js` and should not be edited directly.

## Validate

```sh
node build.js
git diff -- theme.css
```

Run the visual audit when Obsidian is available:

```sh
open -a Obsidian --args --remote-debugging-port=9222 --remote-allow-origins=*
python3 scripts/visual-audit.py
```

## Editing Rules

- OKLCH colors belong in token/source modules; do not introduce hex colors.
- Plugin-specific selectors go in `src/plugins/`.
- Use `body` prefixes where needed to beat Obsidian `app.css`.
- Keep CDP docs and helper scripts on port `9222`.

## Screenshots

Screenshots should cover light, dark, callouts, and representative workspace/editor states. Prefer CDP screenshots from a real Obsidian vault over static mockups.
